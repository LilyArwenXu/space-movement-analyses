微观数据分析

视线朝向关系图

从body.csv中读取人体的GlobalRootOrientation和各关节的 LocalOrientationPerJoint。首先以人体根部旋转作为基础，按照 骨盆 → 脊柱 → 颈部 → 头部 的骨骼层级，将各关节的四元数旋转逐级相乘，得到头部在世界坐标中的整体旋转。再将头部的前向向量旋转到世界坐标，并投影到水平面，通过 atan2 计算其方向角，转换为 0°–360°。最后按 1 秒采样，每个 ID 每秒保留一个点，用散点表示不同人的朝向变化。

平面速度轨迹图

从 body.csv 中读取每个人的 Id、Position 和 Velocity。其中 Position 提供人体在空间中的 X、Y 坐标，Velocity 提供人体在 X、Y 方向上的运动速度。首先计算水平面上的速度大小： v = √(Vx² + Vy²) 再按照同一 ID 的时间顺序连接各个位置点形成运动轨迹，并将速度大小映射到轨迹颜色：低速偏蓝，高速偏红。

社交距离亲和度图

从 body.csv 中读取每个人的 Id 和 Position，并按帧对应各人的位置。首先计算同一帧中不同 ID 之间的两两距离 d，以 3 m 为邻近阈值，将阈值内的距离转换为亲和度：(3-d)/3，距离越近，数值越高。再对每个人与邻近对象的亲和度取平均，没有邻近对象时记为 0。最后将个体亲和度对应到其平面位置，汇总为空间热力图，并通过高斯平滑形成连续的色彩分布，表示不同位置的邻近程度。

平面空间占用图

从 body.csv 中读取每个人的 Id 和 Position，并根据时间按 1 秒采样，每个 ID 每秒保留一个位置点。首先将位置投影到平面，并把研究区域划分为 0.25 m × 0.25 m 的网格。再将每个采样点归入对应网格，逐次累计占用次数；同一网格中不同人的采样点分别计入，因此数值同时反映出现人数与停留时间。最后将累计值映射为热力颜色，各图采用统一的色阶范围，使不同区域或时段的空间占用情况可以直接比较。

姿态混合度范围图

Grasshopper 直接读取 body.csv 中的 Id、左膝盖和骨盆位置，通过两者的高度差判断人体为坐姿或站姿，并根据不同 ID 的空间位置生成范围圈。红色表示坐姿 ID 范围，蓝色表示站姿 ID 范围，反映不同姿态在空间中的分布。
